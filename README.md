# API Aggregator

Курсовой проект по ООП: консольное Java-приложение для параллельной агрегации данных из нескольких открытых REST API.

## Цели проекта

- Получать данные из разных REST API по HTTP и приводить их к единому формату записи
- Сохранять агрегированные данные в файл (JSON или CSV) и читать их обратно
- Опрашивать источники параллельно с ограничением числа одновременных задач и с заданным интервалом между запросами
- Разделить ответственность между слоями (получение данных / обработка / хранение / CLI), чтобы новый API можно было добавить, не трогая основную логику

## Что делает приложение

- Работает в двух режимах:
  - **Автоматический** — параметры задаются аргументами командной строки (`--apis`, `--format`, `--file`, `--threads`, `--interval`, `--continuous`)
  - **Интерактивный** — меню в консоли: выбор API, формата вывода, режима записи (новый файл / дозапись), запуск и остановка опроса, просмотр содержимого файла целиком или по конкретному API
- Опрашивает выбранные API по HTTP, парсит JSON-ответ и преобразует его в Java-объект записи (`id`, `source`, `timestamp`, `data`)
- Сохраняет записи в JSON или денормализованный CSV с потокобезопасной записью в файл
- Поддерживает разовый параллельный опрос и непрерывный опрос с заданным интервалом `t` и пулом из `n` потоков, с корректной остановкой и освобождением ресурсов

### Используемые API

| API | Данные |
|---|---|
| [JSONPlaceholder](https://jsonplaceholder.typicode.com/) | тестовые данные пользователя |
| [ip-api.com](https://ip-api.com/) | геолокация по IP |
| [Open-Meteo](https://open-meteo.com/) | текущая погода по координатам |

## Инструменты и технологии

- **Java 17**, сборка — **Maven**
- HTTP-запросы — `java.net.http.HttpClient` (встроенный в JDK)
- Парсинг и сериализация JSON — **Jackson** (`jackson-databind`, `jackson-datatype-jsr310`)
- Параллелизм — `java.util.concurrent` (`ExecutorService`, `Executors`, `ReentrantLock`, `AtomicBoolean`)
- Тестирование — **JUnit 5** + **Mockito**
- Покрытие тестами — **JaCoCo**
- Сборка исполняемого jar — **maven-shade-plugin**

## Сборка и запуск

Сборка (компиляция, тесты, отчёт о покрытии, jar-файл):

```bash
mvn clean package
```

Отчёт о покрытии после сборки: `target/site/jacoco/index.html`

Интерактивный режим:

```bash
java -jar target/api-aggregator-stage1-1.0-SNAPSHOT.jar
```

Автоматический режим, пример:

```bash
java -jar target/api-aggregator-stage1-1.0-SNAPSHOT.jar \
  --apis jsonplaceholder,ip-api,open-meteo \
  --format json \
  --file output.json \
  --threads 3 \
  --interval 5 \
  --continuous
```

Параметр `--continuous` включает непрерывный опрос с интервалом `--interval` секунд; без него выполняется однократный параллельный опрос.

## Структура проекта

```
src/main/java/ru/mtuci/aggregator/
├── api/            интерфейс ApiProvider и его реализации для каждого API
├── cli/            интерактивный и автоматический режимы ввода
├── concurrent/     управление пулом потоков и периодическим опросом
├── config/         реестр доступных API
├── model/          модель агрегированной записи
├── parser/         разбор JSON-ответов
├── service/        бизнес-логика агрегации
└── storage/        чтение/запись в JSON и CSV
```
